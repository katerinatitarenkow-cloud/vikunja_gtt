FIX5 — получение данных Wialon

Исправления:
1. Remote API запросы формируются совместимо с официальной Wialon Postman collection: POST с svc/params/sid в query string.
2. Админская проверка подключения теперь возвращает конкретный этап ошибки (token/login или core/search_items) и код Wialon.
3. Токен в сообщениях об ошибках не выводится.

Замена:
Распакуйте архив в корень текущего исходника Vikunja с заменой файлов.
Затем выполните:
  .\BUILD-WINDOWS-FIXED-v2.ps1
Запустите новый release\vikunja.exe.

Базу данных удалять не нужно. Повторно получать токен тоже не нужно: сохранённый токен останется в БД.
