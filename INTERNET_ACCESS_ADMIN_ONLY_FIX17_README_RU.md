# FIX17 — Internet Access + Admin-only Users

Устанавливается поверх текущего исходника Vikunja с FIX16.

## Что исправляет

### 1. Один web-build работает по любому адресу

В браузерной версии API всегда вызывается по тому же origin, по которому открыта Vikunja:

- `http://127.0.0.1:3456`
- `http://192.168.x.x:3456`
- `http://PUBLIC_IP:3456`
- `https://vikunja.example.com`

Web-версия больше не использует сохранённый в `localStorage` старый `API_URL`. Это устраняет ситуацию, когда страница по внешнему IP открывается, но login показывает `Network Error`, потому что браузер пытается отправлять API-запросы на старый localhost/старый сервер.

Desktop-режим при этом сохраняет возможность выбирать сервер и хранить его URL.

### 2. CORS отключён для standalone web

Frontend и API встроены в один `vikunja.exe` и работают с одного origin, поэтому CORS для обычной web-версии не нужен. Это безопаснее, чем разрешать API для произвольных внешних origin.

`service.interface` остаётся `:3456`, то есть сервер слушает все сетевые интерфейсы компьютера.

### 3. Саморегистрация отключена

`service.enableregistration: false`.

Также default backend изменён на `false`, поэтому если настройка отсутствует, публичная регистрация всё равно не включится сама.

### 4. Кнопка «Регистрация» удалена

На странице входа больше нет:

- «Ещё нет аккаунта?»
- «Создать аккаунт»

Прямой переход на `/register` перенаправляет на `/login`.

Пользователей создаёт администратор через существующее админское управление пользователями/командой.

## Важно про внешний интернет

FIX17 исправляет приложение, но не может сам настроить домашний/офисный маршрутизатор.

Чтобы открыть Vikunja из внешнего интернета, до компьютера должен уже доходить TCP-трафик на 3456 (публичный IP + port forwarding/firewall) либо должен использоваться reverse proxy/VPN/tunnel.

Если страница Vikunja уже открывается по внешнему IP, сетевой маршрут у вас уже есть — после FIX17 API/login будет использовать этот же внешний адрес автоматически.

Для постоянной публичной эксплуатации рекомендуется HTTPS через reverse proxy. `service.publicurl` в поставляемом config оставлен пустым, чтобы сборка не была жёстко привязана к `localhost` или одному IP. Когда будет постоянный домен, его можно указать там для абсолютных ссылок/почтовых уведомлений.

## Установка

1. Остановить Vikunja.
2. Распаковать ZIP в корень исходников с заменой файлов.
3. Запустить:

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

4. Запустить `release\RUN.cmd`.
5. В браузере сделать `Ctrl+F5`.

После обновления старый web `API_URL` автоматически удалится из localStorage.
