FIX3: Wialon не виден в настройках / bootstrap admin

1. Скопируйте содержимое этого архива в корень исходников Vikunja с заменой файлов.
2. Пересоберите: .\BUILD-WINDOWS-FIXED-v2.ps1
3. Запустите новый release\vikunja.exe.
4. При первом запуске новая миграция 20260819115000:
   - если в базе вообще нет is_admin=true,
   - и существует пользователь с логином admin,
   он будет назначен системным администратором и добавлен в группу «Админ».
5. После входа откройте Настройки -> Wialon.

Также команда `vikunja user set-admin <username> --admin` в этой custom-сборке больше не требует Pro Admin Panel license. Pro-функции upstream по-прежнему остаются отдельно лицензионно ограничены.
