# CRM PATCH 3/3 — FIX11C

Этот патч устанавливается **только поверх CRM PATCH 2/3 (FIX11B)**.

## Что добавлено

### 1. Множество контактных лиц
У одного клиента/компании можно хранить произвольное количество контактных лиц.

Для каждого контакта доступны:
- ФИО;
- должность;
- отдел;
- телефон;
- email;
- Telegram;
- Viber;
- WhatsApp;
- день рождения;
- предпочтительный канал связи;
- примечание;
- роль в принятии решения.

Роли:
- Руководитель;
- Принимает решение;
- Технический специалист;
- Закупщик;
- Бухгалтер;
- Пользователь;
- Другое.

Контактные лица хранятся как отдельные структурированные записи CRM и не являются пользователями Vikunja, поэтому их наличие не меняет права доступа.

### 2. Коммерческое предложение PDF
В карточке клиента появился отдельный блок «Коммерческое предложение».

Поддерживается:
- загрузка одного PDF;
- замена существующего PDF;
- скачивание;
- удаление.

Файл хранится штатным файловым механизмом Vikunja. Backend проверяет содержимое файла и принимает только PDF, а не просто файл с расширением `.pdf`.

CRM-файл не доступен через публичный link-share проекта.

### 3. Финальная полировка карточки
Добавлены:
- краткая сводка в шапке карточки клиента: статус, ответственный, число контактных лиц;
- аккуратные карточки контактных лиц;
- пустые состояния для контактов и коммерческого предложения;
- адаптивное отображение на узких экранах;
- исправление общего HTTP interceptor для корректных multipart/FormData загрузок.

## Миграция БД

Добавляется миграция:

`20260820120000`

Она:
- добавляет `commercial_proposal_file_id` в `client_profiles`;
- создаёт таблицу `client_contact_persons`.

Существующую базу данных удалять **не нужно**.

## Новые API endpoints

- `PUT /api/v2/projects/{project}/client/proposal` — загрузить/заменить PDF;
- `GET /api/v2/projects/{project}/client/proposal` — скачать PDF;
- `DELETE /api/v2/projects/{project}/client/proposal` — удалить PDF.

Контактные лица читаются и сохраняются вместе с обычным CRM-профилем через:

- `GET /api/v2/projects/{project}/client`;
- `PUT /api/v2/projects/{project}/client`.

## Права

- просмотр CRM и PDF требует права чтения проекта;
- изменение контактов и PDF требует права изменения проекта;
- публичные link-share не получают доступ к CRM-профилю и PDF.

## Установка

1. Убедитесь, что уже установлен PATCH 1/3 (FIX11A) и PATCH 2/3 (FIX11B).
2. Остановите Vikunja.
3. Распакуйте этот ZIP **в корень исходников Vikunja с заменой файлов**.
4. Выполните:

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

5. Запустите новый файл:

```powershell
.\release\vikunja.exe
```

6. После запуска обновите страницу через `Ctrl+F5`.

При первом запуске новая миграция выполнится автоматически.

## Проверка после установки

Откройте любой обычный проект → вкладка **Клиент**.

Проверьте:
1. «Добавить контакт» создаёт новую карточку контактного лица.
2. После заполнения и «Сохранить» контакт остаётся после перезагрузки страницы.
3. Роль контакта сохраняется.
4. «Загрузить PDF» принимает настоящий PDF.
5. PDF можно скачать, заменить и удалить.
6. Клиентская карточка продолжает сохранять данные PATCH 1 и PATCH 2.

## Совместимость

PATCH 3 является завершающим слоем CRM FIX11C и не заменяет PATCH 1 или PATCH 2 при поэтапной установке.

Полный SOURCE FIX11C уже содержит все три CRM-патча вместе.
