# CRM — патч 2 из 3 (FIX11B)

База: **CRM PATCH 1/3 — FIX11A**, установленный поверх GreenTech UI + Structured Subtasks FIX10.

## Что добавляет этот патч

### 1. Юридические данные

Блок показывается только если тип клиента — **ФОП** или **Компания**. Для физлица он скрыт.

Добавлены поля:

- ЄДРПОУ / ИНН;
- название юридического лица;
- ФИО директора;
- форма собственности;
- отрасль;
- количество сотрудников;
- реквизиты;
- IBAN;
- банк;
- МФО;
- номер плательщика НДС;
- система налогообложения.

Поле сайта не дублируется: используется уже существующее поле «Сайт» из контактных данных клиента.

### 2. Пять независимых адресов

У каждого проекта-клиента есть фиксированные типы адресов:

1. Юридический;
2. Фактический;
3. Почтовый;
4. Адрес доставки;
5. Адрес объекта.

Каждый адрес хранится структурировано:

`Страна → область → город → улица → дом → офис → индекс`

В БД гарантируется максимум одна запись каждого типа адреса для одного проекта.

### 3. Автоматический индекс

Когда заполнены страна, город, улица и дом, после выхода из поля интерфейс пытается определить адрес через backend Vikunja.

Backend обращается к OpenStreetMap Nominatim и возвращает:

- индекс;
- широту;
- долготу;
- найденное представление адреса.

Если индекс уже введён вручную, автоматический поиск его не перезаписывает.

Запросы к публичному Nominatim на стороне Vikunja сериализованы с интервалом не менее одной секунды.

### 4. «Показать на карте»

У каждого адреса есть кнопка **«Показать на карте»**.

После нажатия:

1. Vikunja уточняет координаты адреса;
2. сохраняет координаты в текущей форме;
3. при наличии индекса автоматически подставляет его;
4. под адресом раскрывается карта OpenStreetMap с маркером.

Координаты сохраняются вместе с карточкой клиента после нажатия «Сохранить карточку».

## Доступ и приватность

Адреса и юридические реквизиты используют тот же доступ, что и CRM-карточка из патча 1:

- пользователь должен иметь доступ к проекту;
- редактирование требует права записи проекта;
- публичные link-share не получают CRM-данные и не могут использовать CRM-геокодирование.

## База данных

При первом запуске автоматически выполняется миграция:

`20260820113000`

Она:

- добавляет юридические поля в существующую таблицу `client_profiles`;
- создаёт таблицу `client_addresses`.

Удалять существующую SQLite-базу **не нужно**.

## Интернет для карты и индекса

Для автоматического определения индекса сервер Vikunja должен иметь доступ к:

`https://nominatim.openstreetmap.org`

Для отображения встроенной карты браузеру нужен доступ к:

`https://www.openstreetmap.org`

Если интернет недоступен, карточка и ручное заполнение адреса продолжают работать, но автоматический индекс и карта не загрузятся.

## Установка

1. Убедиться, что PATCH 1 / FIX11A уже установлен.
2. Остановить Vikunja.
3. Распаковать этот архив в корень исходников **с заменой файлов**.
4. Выполнить:

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

5. Запустить:

```powershell
.\release\vikunja.exe
```

6. После запуска сделать `Ctrl+F5` в браузере.
