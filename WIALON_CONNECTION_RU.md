# Подключение Wialon в Vikunja

Интеграция использует Wialon Remote API и авторизацию по access token (`token/login`).
Логин/пароль Wialon в Vikunja не сохраняются.

Для Wialon Hosting:
1. Войдите в Vikunja под системным администратором.
2. Откройте Настройки -> Wialon.
3. Оставьте API URL `https://hst-api.wialon.com`.
4. Нажмите «Получить токен Wialon Hosting», авторизуйтесь на стороне Wialon и скопируйте `access_token`.
5. Вставьте токен, включите интеграцию, сохраните и нажмите «Проверить подключение».

Текущий адаптер использует:
- `token/login` — авторизация;
- `core/search_items` — список машин, последняя позиция и состояние связи;
- `messages/load_interval` — GPS-сообщения за период для построения фактического трека.

Внимание: текущая «линия маршрута» — фактически пройденный GPS-трек. Плановые сущности Wialon Routes/Rides пока не импортируются.
