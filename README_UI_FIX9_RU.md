# GreenTech UI FIX9

Визуальная переработка интерфейса Vikunja под стиль Green Tech Trade.

## Направление

- тёмный фирменный зелёный для структуры интерфейса;
- салатовый цвет логотипа — только как акцент, а не основной фон;
- светлый тёплый фон рабочей области;
- более крупные радиусы, мягкие границы и лёгкие тени;
- спокойная плотность интерфейса без декоративной перегрузки;
- единый стиль кнопок, форм, карточек, Kanban и Wialon.

## Основные изменения

- новый фирменный design-token слой `frontend/src/styles/greentech.scss`;
- тёмная боковая навигация с салатовыми активными пунктами;
- фирменный logo.png используется в шапке/навигации;
- белая полупрозрачная верхняя панель;
- современные кнопки без ALL CAPS;
- формы 40px, более заметный focus-state;
- карточки с радиусом 14px и мягкой зелёной тенью;
- Kanban-колонки и карточки переработаны визуально;
- карточка задачи получила более чистую структуру;
- Home и Quick Add стали выглядеть как dashboard;
- Wialon приведён к тому же стилю.

## Установка

Распаковать архив в корень текущего исходника с заменой файлов и выполнить:

    .\BUILD-WINDOWS-FIXED-v2.ps1

После запуска сделать Ctrl+F5 из-за Service Worker.

## Важно

FIX9 меняет только frontend/стили. Backend, база, Wialon API, группы и права не меняются.
