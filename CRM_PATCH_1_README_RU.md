# CRM — патч 1 из 3

База: **Vikunja Custom GreenTech UI + Structured Subtasks FIX10**.

## Что реализует этот патч

1. Каждый обычный проект становится карточкой клиента на уровне интерфейса.
2. При открытии проекта первой открывается вкладка **«Клиент»**.
3. В переключателе представлений вкладка **«Клиент»** стоит перед Список / Гант / Таблица / Канбан.
4. Публичные link-share проекта не получают доступ к CRM-карточке.
5. Добавляется базовая CRM-карточка:
   - тип: Физлицо / ФОП / Компания;
   - название компании / имя клиента;
   - ФИО основного контакта для компании;
   - статус: Потенциальный / Активный / Неактивный / VIP;
   - ответственный сотрудник;
   - источник: сайт / рекомендация / реклама / холодный контакт;
   - дата добавления (автоматически из даты создания проекта);
   - основной и дополнительный телефон;
   - основной и дополнительный email;
   - Telegram / Viber / WhatsApp;
   - сайт;
   - предпочтительный канал связи;
   - предпочтительный язык.
6. Ответственный выбирается только из пользователей, которые уже имеют доступ к проекту.
7. При назначении нового ответственного он получает уведомление Vikunja со ссылкой на карточку клиента.
8. Название проекта синхронизируется с полем названия/имени клиента.
9. При удалении проекта базовая CRM-запись также удаляется.

## Что намеренно НЕ входит в патч 1

Это будет добавлено следующими отдельными патчами:

### Патч 2
- юридические данные компании / ФОП;
- пять типов адресов;
- страна → область → город → улица → дом → офис → индекс;
- геокодирование и «Показать на карте».

### Патч 3
- несколько контактных лиц;
- должность / отдел / мессенджеры / день рождения / заметки;
- роль в принятии решения;
- PDF коммерческого предложения;
- финальная полировка CRM-карточки.

## Установка

1. Остановить Vikunja.
2. Распаковать архив **в корень исходников FIX10** с заменой файлов.
3. Выполнить:

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

4. Запустить новый:

```powershell
.\release\vikunja.exe
```

5. После запуска сделать `Ctrl+F5` в браузере.

## База данных

При первом запуске автоматически выполнится миграция:

`20260820110000`

Она создаёт только таблицу:

`client_profiles`

Удалять существующую SQLite-базу **не нужно**. Wialon, пользователи, группы, задачи и структурированные подзадачи остаются на месте.
