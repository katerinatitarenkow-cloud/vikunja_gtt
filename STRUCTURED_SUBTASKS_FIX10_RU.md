# FIX10 — структурированные подзадачи внутри задачи

## Что добавлено

В карточке задачи появился отдельный блок **«Подзадачи»** в виде списка с галочками.

- Пользователь с правом редактирования родительской задачи может создавать, отмечать и удалять пункты.
- Пользователь только с правом чтения видит список, но не может менять состояние пунктов.
- Для выполненного пункта сервер сохраняет пользователя и точное время выполнения.
- При наведении на выполненный пункт интерфейс показывает: **кто выполнил · когда**.
- Показывается прогресс `Выполнено N из M` и полоска прогресса.
- Когда выполнены все пункты, родительская задача автоматически помечается выполненной штатным механизмом Vikunja.
- Если снять галочку с пункта либо добавить новый незавершённый пункт, автоматически выполненная задача снова становится незавершённой.
- Если список пуст, его наличие само по себе не меняет статус родительской задачи.
- Для повторяющейся задачи после перехода к следующему повторению структурированный список сбрасывается в незавершённое состояние.

## Права

Пункты наследуют права родительской задачи. Отдельной системой доступа они не являются.

Для изменения нужны одновременно:

1. глобальное право на изменение задач в нашей системе ролей;
2. право записи в конкретную задачу/проект Vikunja.

## База данных

Миграция `20260819165000` автоматически создаёт таблицу:

`task_checklist_items`

Основные поля:

- `task_id`
- `title`
- `done`
- `completed_by_id`
- `completed_at`
- `position`
- `created`
- `updated`

Существующую базу удалять или пересоздавать не нужно.

## API

Добавлены маршруты API v2:

- `GET /api/v2/tasks/{task}/checklist-items`
- `POST /api/v2/tasks/{task}/checklist-items`
- `PUT /api/v2/tasks/{task}/checklist-items/{item}`
- `DELETE /api/v2/tasks/{task}/checklist-items/{item}`

## Установка поверх FIX9

Распаковать патч в корень исходников с заменой файлов и выполнить:

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

Затем запустить новый `release\vikunja.exe`.

Настройки Wialon, пользователи, группы и существующая SQLite БД сохраняются.
