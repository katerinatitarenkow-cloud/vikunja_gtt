# Интеграция Wialon и управление доступом

## Wialon

В Vikunja добавлена отдельная страница **Wialon** (`/wialon`) с картой транспорта и фактическими GPS-маршрутами.

Frontend обращается только к backend Vikunja:

- `GET /api/v2/wialon/status` — состояние интеграции;
- `GET /api/v2/wialon/units` — машины, последняя GPS-позиция и состояние связи;
- `GET /api/v2/wialon/units/{unit}/track?from=...&to=...` — GPS-трек машины за период.

Токен Wialon никогда не возвращается frontend.

### Настройка подключения

Подключение теперь настраивается из интерфейса:

**Настройки → Wialon**

Эта вкладка доступна только пользователю с системным флагом `is_admin`.

Администратор может:

- включить/выключить интеграцию;
- указать API URL Wialon;
- задать или заменить токен;
- удалить сохранённый токен;
- задать timeout;
- ограничить число точек трека;
- проверить подключение и увидеть число доступных объектов.

Настройки сохраняются в БД (`wialon_settings`). Сохранённый токен не отдаётся браузеру: интерфейс видит только признак `token_configured`.

Параметры `wialon` в `config.yml` сохранены как fallback для совместимости со старой конфигурацией. После первого сохранения через UI используются настройки из БД.

## Группы и глобальные права

Добавлен независимый от штатных Vikunja Teams слой глобального доступа.

После миграции автоматически существуют две системные группы:

- **Админ** — системные администраторы, все глобальные права;
- **Пользователи** — обычные пользователи. Изначально имеет все глобальные права, чтобы обновление не ломало прежнее поведение. Администратор может сузить её права.

Пользователь может входить в несколько обычных/пользовательских групп. Эффективные права объединяются.

Доступные глобальные права:

- просмотр проектов;
- создание/изменение проектов;
- просмотр задач;
- создание/изменение задач;
- просмотр меток;
- управление метками;
- просмотр команд Vikunja;
- управление командами Vikunja;
- использование Kanban;
- учёт времени;
- просмотр Wialon и маршрутов.

Эти права не заменяют штатные права конкретного проекта Vikunja. Для доступа должны одновременно выполняться глобальное разрешение и штатные ограничения конкретного проекта/задачи.

## Управление командой

Для системного администратора добавлена вкладка:

**Настройки → Управление командой**

Она работает независимо от upstream Pro Admin Panel и требует только `is_admin`.

На вкладке можно:

- создавать пользователей даже при выключенной публичной регистрации;
- открывать карточку пользователя;
- редактировать имя, email, телефон и заметки;
- менять статус пользователя;
- назначать/снимать системный статус администратора;
- назначать одну или несколько групп доступа;
- создавать пользовательские группы;
- задавать права каждой группе;
- удалять пользовательские группы.

Системные группы **Админ** и **Пользователи** удалить нельзя. Группа **Админ** синхронизируется с существующим флагом `users.is_admin`, поэтому членство в ней нельзя использовать как обход выдачи системных админ-прав.

## База данных

Миграция `20260819090000` создаёт:

- `access_groups`;
- `access_group_permissions`;
- `access_group_members`;
- `user_profiles`;
- `wialon_settings`.

Существующие администраторы автоматически попадают в **Админ**, остальные пользователи — в **Пользователи**.

## Подготовка к интеграции Wialon ↔ Kanban

Wialon-клиент вынесен в `pkg/integrations/wialon`, поэтому тот же серверный слой можно использовать для будущей связи:

```text
задача Vikunja
    ↕
транспортное задание / binding
    ↕
машина Wialon + точка/геозона
```

Следующий этап можно строить без переделки текущей карты: добавить привязку `task_id ↔ unit_id ↔ destination`, правила прибытия и автоматическое изменение состояния Kanban-задачи.

## Сборка Windows

После замены файлов нужно пересобрать приложение:

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

Скрипт проверяет исправность `frontend/node_modules`; при повреждённых pnpm-ссылках выполняет `pnpm install --frozen-lockfile`, затем собирает frontend и backend.

Готовый файл:

```text
release\vikunja.exe
```

Исходный `vikunja.exe` из базового архива не содержит эти изменения.
