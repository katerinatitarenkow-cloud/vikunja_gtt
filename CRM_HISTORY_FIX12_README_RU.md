# CRM History — FIX12

Полный накопительный SOURCE Vikunja Custom GreenTech CRM с историей работы с клиентом.

Включает предыдущие доработки проекта, CRM FIX11A/FIX11B/FIX11C и FIX12.

## FIX12: История клиента

Вкладки обычного клиентского проекта:

`Клиент → Список → Гант → Таблица → Канбан → История`

Добавлена универсальная таблица `client_activity_events` и миграция `20260820130000`.

### Ручные активности

- звонок;
- сообщение;
- встреча;
- заметка;
- отправленный документ;
- отправленное коммерческое предложение;
- отправленный счёт.

Для активностей предусмотрены структурированные данные: контактное лицо, направление, канал, дата/время, длительность, результат и дополнительные сведения.

### Автоматическая история

Автоматически фиксируются:

- создание задачи;
- завершение задачи;
- повторное открытие задачи;
- комментарий к задаче;
- изменение статуса клиента;
- смена ответственного;
- загрузка коммерческого предложения;
- замена коммерческого предложения;
- удаление коммерческого предложения.

Системные события защищены от ручного удаления. Пользовательские CRM-активности можно удалить через интерфейс истории.

### Архитектура связанных сущностей

События поддерживают универсальную связь через `entity_type + entity_id`, поэтому тот же журнал можно дальше использовать для сделок, документов, счетов, объектов, оборудования и Wialon без создания отдельной истории для каждого модуля.

### Доступ

История использует права клиентского проекта. Публичные link-share не получают доступ к CRM-карточке или истории клиента.

## База данных

Существующую SQLite-базу удалять не нужно. При первом запуске FIX12 миграция создаст `client_activity_events` автоматически.

## Сборка Windows

```powershell
.\BUILD-WINDOWS-FIXED-v2.ps1
```

После сборки запустить новый `release\vikunja.exe` и выполнить `Ctrl+F5` в браузере.
